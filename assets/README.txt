Папка assets — стоковые статичные файлы FRX (логотипы, картинки, шаблоны и т.п.).

- Получить путь к файлу из модуля:
      engine.asset_path('logo.png')     # выйти за пределы папки ассетов нельзя
  Сначала ищется в user/assets/ (свои файлы), затем здесь — так свой файл
  с тем же именем подменяет стоковый.
- Свои файлы кладите в user/assets/ (или загружайте на сайте .web, вкладка
  «files»). Пользовательские данные — вложения, бэкапы — живут в user/data/.
- Папка входит в состав FRX и обновляется вместе с кодом (.update): новые и
  изменённые стоковые файлы добавляются, лишние не удаляются.
